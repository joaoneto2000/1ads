# Pong em Java

Um Pong simples para um jogador: controle a raquete da esquerda contra o computador.

## Como executar

É necessário ter o JDK instalado. No terminal, na pasta do projeto:

```bash
javac Pong.java
java Pong
```

## Controles

- `W`: move a raquete para cima
- `S`: move a raquete para baixo
- `ESPAÇO`: reinicia o placar e a partida
